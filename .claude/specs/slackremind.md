# Slack /remind ジェネレーター 仕様書

## 目的・概要

Slack の `/remind` コマンドは英語構文（`in 30 minutes` / `every Monday at 9am` 等）を覚える必要があり、日本人ユーザーには学習コストが高い。本ツールは「フォームで日本語入力 → 正しい英語の `/remind` コマンドを即時生成」する Web ジェネレーター。ブラウザ完結・コピー一発で Slack に貼り付け可能。

## 対象ユーザーとユースケース

- 想定ユーザー: Slack 初心者〜パワーユーザー双方（日本語話者）
- ユースケース:
  - 日々の業務リマインド（例: 30分後に会議準備リマインドをセット）
  - チームの定例リマインド（例: 毎週月曜9時に朝会リマインドを #team に投稿）
  - 個人タスクの先送り（例: 明日15時にレビュー依頼を自分宛にリマインド）

## 既存ツールとの関係

- 重複ツール: 無し
- 類似ドメイン: `slackemojigen/`（Slack 周辺ユーティリティ）— FAQ・関連ツール欄で相互リンク
- クロスリンク候補: `slackemojigen`、`mdkanban`（タスク管理つながり）

## 機能要件

### 必須機能（MVP）

**F1: 宛先選択**
- 3種から選択: `me`（自分） / `@user`（個人） / `#channel`（チャンネル）
- `@user` / `#channel` 選択時はテキスト入力欄を表示
- 入力欄の値は先頭の `@` / `#` を除去して保存（生成時に prefix を付与）。`@alice` / `alice` のどちらの入力でも正しく動作
- プレースホルダーで形式例を提示（例: `alice`、`general`）

**F2: リマインド内容入力**
- 日本語そのままでOKの自由記述テキストエリア
- 1〜2行想定。改行も含めてコマンド本文に展開
- 入力例の表示（プレースホルダー: 例 `議事録を送る`）

**F3: 日時指定（タブ切替で4モード）**

- **モード1: 相対時間** — 数値入力 + 単位選択（分後 / 時間後 / 日後）
  - 例: `30` `分後` → `in 30 minutes`
- **モード2: 今日/明日/明後日 + 時刻** — ラジオで日選択 + 時刻ピッカー
  - 例: `明日` `15:00` → `at 3pm tomorrow`
- **モード3: 日付指定 + 時刻** — `<input type="date">` + 時刻ピッカー
  - 例: `2026-06-01` `9:00` → `at 9am on June 1st`
  - 過去日付選択時はエラー表示
- **モード4: 繰り返し** — パターン選択 + 時刻
  - パターン: 毎日 / 平日 / 週末 / 毎週N曜日（複数曜日選択可） / 毎月N日
  - 例: 毎週 `月`+`水` `9:00` → `every Monday, Wednesday at 9am`

**F4: リアルタイムプレビュー**
- フォーム入力に追従して、画面上部のプレビューカードに生成コマンドを即時表示
- 等幅フォント。コマンド部分／本文／日時部分で軽く色分け
- `aria-live="polite"` 領域として宣言

**F5: 「こう解釈される」説明**
- プレビュー下に、生成された英語日時部分の日本語訳を表示
- 例: `in 30 minutes` → 「30分後に通知されます」
- 繰り返しの場合: 「毎週月曜・水曜の朝9時に繰り返し通知されます」など

**F6: コピーボタン**
- ワンクリックでクリップボードにコピー
- 押下後に「コピーしました」トースト表示（約2秒）
- 入力不備時はエラー表示し、コピーは実行しない

**F7: 履歴／お気に入り（LocalStorage）**
- 生成したコマンドを履歴として保存（最新20件）
- ★ボタンでお気に入り登録 → お気に入りタブで再表示
- 履歴から復元（クリックで全フォームを当時の状態に戻す）
- 全削除ボタン
- 履歴に追加するタイミングは「コピーボタン押下に成功した時」とする（プレビュー更新ごとではない）

### オプション機能（次フェーズ候補）

- O1: よく使うパターンのテンプレート集（「毎週月曜の朝会」など、ボタン一発でフォーム反映）
- O2: 生成コマンドの QR コード化
- O3: タイムゾーン明記（Slack ワークスペース設定TZに準拠する旨の注意書き）

## 入出力の定義

### 入力
- 宛先種別: `me` / `@user` / `#channel`
- 宛先テキスト（`@user` / `#channel` 時のみ、1〜80文字、半角英数・ハイフン・アンダースコア・ピリオド）
- リマインド本文: 任意のテキスト（1〜500文字、改行可）
- 日時: 4モードのいずれか1つを満たす入力

### 出力
- 表示: 1行の `/remind ...` 文字列
- コピー: 同文字列をクリップボードへ
- 永続化: 履歴・お気に入りを LocalStorage に保存（外部送信なし）

## 日時変換ルール（重要）

英語表現はすべてクライアントサイドで生成する。Slack 公式の構文に従う:

- 相対時間:
  - `N 分後` → `in N minutes`（N=1のときも `in 1 minute`）
  - `N 時間後` → `in N hours`（N=1のときも `in 1 hour`）
  - `N 日後` → `in N days`（N=1のときも `in 1 day`）
- 今日/明日/明後日:
  - 今日 → `today`、明日 → `tomorrow`、明後日 → 日付指定で `at TIME on MONTH DAYth` の形式へフォールバック（Slack は明後日のキーワードを持たない）
  - 時刻表記: 12時間制で `at 3pm` / `at 9am` / `at 12:30pm` 等。0分の場合は `at 3pm`、それ以外は `at 3:30pm`。0時は `12am`、12時は `12pm`、`noon` / `midnight` は使用しない（曖昧回避）
- 日付指定:
  - `at TIME on MONTH DAYth, YEAR` 形式（年は当年なら省略、それ以外は付与）
  - 月名: January, February, ... December
  - 序数: 1st, 2nd, 3rd, 4th, ... 21st, 22nd, 23rd, 24th, ... 31st
- 繰り返し:
  - 毎日 → `every day at TIME`
  - 平日 → `every weekday at TIME`
  - 週末 → `every Saturday, Sunday at TIME`
  - 毎週N曜日（複数選択可） → `every Monday, Wednesday at TIME`（日〜土を月→日の順で並べる）
  - 毎月N日 → `every 15th of the month at TIME`

時刻入力（`<input type="time">`）の値を上記英語表記に変換するヘルパー関数を script.js に実装する。

## UI・UX要件

### 画面構成（縦並び、上から順）
1. ヘッダー（ツール名・サブタイトル）
2. プレビューカード（生成コマンド + コピーボタン + 「こう解釈される」説明）
3. 入力フォーム
   - ステップ①「だれに」: 宛先ラジオ + 入力欄
   - ステップ②「なにを」: 本文テキストエリア
   - ステップ③「いつ」: 4タブ（相対時間 / 今日明日 / 日付指定 / 繰り返し）
4. 履歴・お気に入りパネル（折りたたみ可、タブ切替）
5. SEO コンテンツセクション（使い方 HowTo・FAQ・関連ツール紹介）
6. フッター（ツール横断 + サイト情報）

### 操作フロー
1. 宛先を選ぶ → 必要なら名前入力
2. リマインド内容を書く
3. 日時タブを選び、値を埋める
4. プレビューが即時更新
5. コピーボタン → Slack に貼り付け

### フィードバック
- コピー成功: トースト「コピーしました」（約2秒で消える）
- バリデーションエラー: 該当フィールド下に赤字でメッセージ、プレビュー欄は「入力を完成させてください」表示
- お気に入り追加/削除: ボタンアイコン切替（★/☆）＋短いトースト
- 履歴復元: フォーム全体が当時の値に戻る + 軽いハイライト

### エッジケース
- 宛先が `me` 以外で名前が空 → エラー「@ユーザー名 / #チャンネル名 を入力してください」
- 本文が空 → エラー「リマインド内容を入力してください」
- 日付指定モードで過去日付 → エラー「未来の日時を指定してください」
- 相対時間で 0 や負数・空 → エラー「1以上の数値を入力してください」
- 繰り返しで「毎週」を選んだのに曜日未選択 → エラー「曜日を1つ以上選択してください」
- LocalStorage 容量制限超過時 → 古い履歴から削除

## SEO要件

### ターゲットキーワード
- 主: `Slack remind 使い方`、`Slack リマインド 設定`、`Slack /remind 日本語`
- 補: `Slack リマインダー 繰り返し`、`Slack remind 毎週`、`Slack remind コマンド ジェネレーター`

### タイトル・description
- title: `Slack /remind ジェネレーター | 日本語フォームで簡単にリマインドコマンドを作成`
- description: `Slack の /remind コマンドを日本語フォームで作成。自分・個人・チャンネル宛、繰り返し（毎日・毎週・平日）にも対応。コピーしてSlackに貼るだけ。`

### 使い方ステップ（HowTo構造化データ用）
1. リマインドの宛先を選ぶ（自分 / 個人 / チャンネル）
2. リマインド内容を日本語で入力する
3. 日時タブを選び、いつ通知してほしいか指定する
4. プレビューに表示された `/remind ...` をコピー
5. Slack の入力欄に貼り付けて送信

### FAQ項目（FAQPage構造化データ用、5問）
- Q1: 生成したコマンドはSlackのどの画面で使えますか？
  - A: Slack の任意のチャンネル・DM の入力欄に貼り付けて送信できます。送信後は自分にしか見えない確認メッセージが表示されます。
- Q2: 「明日の朝9時」のような自然な指定はできますか？
  - A: フォームの「今日明日」タブで明日を選び、時刻に 09:00 を指定すると `at 9am tomorrow` が生成されます。
- Q3: 設定したリマインダーをあとから削除できますか？
  - A: はい。Slack の入力欄で `/remind list` を実行するとリマインダー一覧が表示され、各項目から削除できます。
- Q4: タイムゾーンはどうなりますか？
  - A: Slack ワークスペースで設定されたタイムゾーンで通知されます。本ツールは時刻文字列を変換するのみです。
- Q5: Slack 絵文字をリマインドと一緒に使いたい
  - A: 本サイトの「Slack絵文字ジェネレーター」（slackemojigen）で絵文字画像を作成 → Slackにアップロード後、リマインド本文に `:emoji_name:` の形で記述できます。
