      メールテンプレート作成ツールとは
      
            
      月次報告・請求書送付・日程調整・お礼状といった定型メールは、宛先や件名、本文の大部分が毎回同じで、変わるのは「取引先名」「対象月」「送付日」といった一部だけです。それでも毎回過去のメールを探して手直しすることになり、日付の書き間違いや直し漏れが起きがちです。
      
            
      本ツールは、固定部分と差し込み部分を分けたメールテンプレートをブラウザに保存し、利用時は差し込み欄を埋めるだけで完成メールを生成します。送付日のように機械的に決まる値は自動で計算されます。出力はプレーンテキストと HTML の両方に対応し、クリップボードへのコピー、mailto: でのメールアプリ起動、.eml ファイルのダウンロードで受け渡せます。テンプレートは JSON でエクスポート／インポートでき、端末間で持ち運べます。
      

            
      使い方
      
            
        
                
      1. 「作成・編集」タブで新規作成し、テンプレート名・宛先・件名・本文を登録します。
        2. 
                
      2. 本文の可変部分を {{取引先名}} のように書くと、未登録の差し込み変数として自動検出されます。
        3. 
                
      3. 検出された変数に種類（1行テキスト／複数行／選択肢／日付）と初期値を設定して保存します。
        4. 
                
      4. 「使う」タブでテンプレートを選び、差し込み欄を入力します。日付の変数は基準日とオフセットから自動計算されます。
        5. 
                
      5. プレーンテキストか HTML を選び、本文をコピーするか、メールアプリで開く・.eml をダウンロードして送信します。
        6. 
            
      

            
      差し込み変数の種類
      
            
        
                
      • 1行テキスト — 取引先名・担当者名など、都度入力する短い値。
        • 
                
      • 複数行テキスト — 備考欄や補足など、改行を含む値。
        • 
                
      • 選択肢 — 担当部署のように決まった候補から選ぶ値。
        • 
                
      • 日付 — 今日・明日・月初・月末などの基準日にオフセット（日／営業日／月）を加えて自動計算。書式は YYYY年M月D日(ddd) などから選べます。
        • 
            
      

            
      よくある質問
      
            
      
                
      
                    入力内容やテンプレートは外部に送信されますか？
                    
      送信されません。テンプレートの保存も含めてすべてお使いのブラウザ内（LocalStorage）で完結します。サーバへのアップロードは一切行わないため、取引先名などを含む定型文でも安心してご利用いただけます。
      
                
      
                
      
                    HTML メールを既定のメールアプリで開けますか？
                    
      mailto: は仕様上プレーンテキストの本文しか渡せないため、HTML 出力時は「メールアプリで開く」を無効にしています。HTML メールを送りたい場合は、「.eml ファイルをダウンロード」して既定のメールアプリで開くか、「本文をコピー」で書式付きコピーを行い、Gmail や Outlook の作成画面に貼り付けてください。
      
                
      
                
      
                    営業日の計算は祝日を考慮しますか？
                    
      土曜・日曜のみをスキップして計算し、祝日には対応していません。祝日を挟む日付を扱う場合は、差し込み欄の「上書きする」にチェックを入れて手動で修正してください。
      
                
      
                
      
                    ブラウザのデータを消すとテンプレートは失われますか？
                    
      失われます。テンプレートはブラウザの LocalStorage にのみ保存されるため、履歴やサイトデータの削除、別の端末・別のブラウザでの利用時には引き継がれません。「データ管理」タブの JSON エクスポートで定期的にバックアップを取り、必要に応じてインポートで復元してください。
      
                
      
                
      
                    HTML メールのスタイルがメールソフトで反映されません
                    
      Gmail をはじめ多くのメールクライアントは <style> ブロックを取り除きます。本ツールではプリセットで指定したフォント・文字色・行間・最大幅をラッパー要素のインライン指定として出力するため比較的反映されやすくなっていますが、「生 CSS を追記する」で書いたスタイルは無視される場合があります。重要な装飾はプリセット側で指定してください。
      
                
      
                
      
                    メールアプリで開こうとすると警告が出るのはなぜですか？
                    
      mailto: の URL 長には環境依存の上限があり、Windows 版 Outlook などでは 2000 文字前後で切り詰められます。本ツールではエンコード後 1800 文字を超えた時点で警告を表示します。長い本文は「本文をコピー」または「.eml ファイルをダウンロード」をご利用ください。
      
                
      
                
      
                    他に業務連絡を効率化するツールはありますか？
                    
      Slack のリマインダー設定を日本語フォームから作れるSlack /remind ジェネレーターや、修正前後の文面を並べて差分を確認できるテキスト比較ツールもあわせてご利用ください。テンプレートを改訂したときの変更点チェックにも役立ちます。
